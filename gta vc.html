Save & Load Guide

Keep your progress safe with a .vcs backup.

HOW TO SAVE READ BECAUSE IT DOESNT SAVE PROCESS

  1. Go to a save point inside Vice City and save your game there.
  2. After saving, press ESC, then SAVE (top right) to download your .vcs backup.
  3. Keep the file. You will need it to restore your progress.

HOW TO LOAD

  1. Choose IMPORT SAVE before playing, or LOAD (top right) during the game.
  2. If no saved game appears at the main menu, select Start New Game → New Game first.
  3. Once gameplay starts, press ESC → Load Game and choose your saved slot.
Load Game empty? Return to gameplay. Open and close the ESC menu twice, then open ESC → Load Game again.
